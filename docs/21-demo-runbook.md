# Demo Runbook (5 minutes)

## Start the system
- From repo root: `docker compose -f infra/docker/docker-compose.yml up -d --build`
- Open the web app: `http://localhost:3000`

## What to show (suggested flow)
1. **Dashboard**
   - Point out the summary strip (zones online/offline, active alerts, offline threshold).
   - Click a zone card to open Zone Detail.
2. **Zone Detail**
   - Change **Metric** and explain the chart reflects historical data.
   - Change **Range** (24h / 7d / 30d) and **Rollup** (5m / 1h / raw) to show dense monitoring controls.
   - Show **Latest** values grid.
3. **Alerts**
   - Open Alerts page, point out severity badges and Ack action.
4. **Events**
   - Switch role to **Admin** and create an event; show it appears in the table.

## Notes
- Mock data is generated by the `mock-generator` service (enabled by default in docker-compose).
